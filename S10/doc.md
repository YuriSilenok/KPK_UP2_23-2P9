# ‌‌‌‌​​​​​​​​​​​​‌​​​​​​​​​​‌​​​​‌‌‌‌‌​​​​​​‌​​​‌​​‌​​​​​​​​‌​​​​‌‌‌​​​​​​​​‌​​​​‌‌​​​‌​​​​​‌​​​​‌‌‌‌‌​​​​​​‌​​​​‌‌‌​‌​​​​​​​​​​​‌​‌‌‌​Вариант 10. Сервис статуса сотрудника

## Команды

### Coздать должность
#### Парамерты передаваемые в запрос
                         
| Параметр     | Пояснение                          | Обязательность | Тип               |      Инвариант     |
| ---          |    ---                             | ---            | ---               |         ---        |
| name         | название должности                 | +              | String            | В пределах 255 символов |
| rate         | ставка                             | +              | Int32 (minor units) | |
| is_part_time | флаг для совместительной должности | +              | Bool              |          -         |

#### Информация при успешном создании
HTTP Response со статусом 201


### Добавление должностей сотруднику по ID 
#### Парамерты передаваемые в запрос

| Параметр     | Пояснение                                                 | Обязательность | Тип               |      Инвариант                 |
| ---          |    ---                                                    | ---            | ---               |         ---                    |
| job_position_ids | идентификаторы должностей добавляемых сотруднику      | +              | Int64[]           | не пустой, значения уникальные |
| employee_id  | идентификатор сотрудника                                  | +              | Int64             |          -                     |

#### Информация при успешном создании
HTTP Response со статусом 201


### Создание отпуска для сотрудника по ID 
#### Парамерты передаваемые в запрос

| Параметр     |        Пояснение         | Обязательность | Тип       |      Инвариант          |
| ---          |            ---           | ---            | ---       |         ---             |
| employee_id  | идентификатор сотрудника |        +       | Int64     | -                       |
| start_time   | Время начала отпуска     |        +       | Timestamp | -                       |
| end_time     | Время концы отпуска      |        +       | Timestamp | Больше чем время начала |

#### Информация при успешном создании
HTTP Response со статусом 201


### Создание больничного для сотрудника по ID
#### Парамерты передаваемые в запрос

| Параметр     | Пояснение                          | Обязательность | Тип               |      Инвариант          |
| ---          |    ---                             | ---            | ---               |         ---             |
| employee_id  | идентификатор сотрудника           |        +       | Int64               | -                       |
| start_time   | Время начала больничного           |        +       | Timestamp       | -                       |
| end_time     | Время концы конца                  |        +       | Timestamp       | Больше чем время начала |

#### Информация при успешном создании
HTTP Response со статусом 201


### Удаление должности по ID 
#### Параметры передаваемые в запрос 
| Параметр         | Пояснение                          | Обязательность | Тип               |      Инвариант          |
| ---              |    ---                             | ---            | ---               |         ---             |
| job_position_id  | идентификатор должности (Path параметр)            |        +       | Int64               | -                       |

#### Информация при успешном удалении
HTTP Response со статусом 200


### Удаление должности у сотрудника по ID 
#### Параметры передаваемые в запрос
| Параметр         | Пояснение                          | Обязательность | Тип               |      Инвариант          |
| ---              |    ---                             | ---            | ---               |         ---             |
| job_position_id  | идентификатор должности (Path параметр) |        +       | Int64               | -                       |
| employee_id      | идентификатор сотрудника (Path параметр) |  + | Int64 | - |         

#### Информация при успешном удалении
HTTP Response со статусом 200
