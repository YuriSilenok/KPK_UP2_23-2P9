## Бизнес-сущности

### Должность

| Поле | Описание | Инвариант | 
| ---  | ---      | ---         |
| Название (name) | Название должности | Уникальная |
| Ставка (rate) | Зарплата должности | Указывается в копейках, не меньше определенного минимума |
| Для совместителей (is_part_time) | Является ли должность совместительной | - | 

### Больничный

| Поле | Описание | Инвариант | 
| ---  | ---      | ---         |
| Начат в (started_at) | Время начала больничного | не может быть больше настоящего времени |
| Окончен в (ended_at) | Время окончания больничного | не может быть меньше времени начала больничного | 
| Сотрудник (employee_id) | Ссылка на сущность сотрудника | уникальный |

### Отпуск

| Поле | Описание | Инвариант | 
| ---  | ---      | ---         |
| Начнется в (starting_at) | Время начала отпуска | - |
| Окончится в (ending_at) | Время окончания отпуска | не может быть меньше времени начала отпуска |


## Команды

1. Возможность создать должность с определённой ставкой:<br/>
    Параметры:
    - Название должности,<br/>
    - Ставка<br/>

2. Возможность добавить несколько должностей сотруднику:<br/>
    Параметры:
    - Список идентификаторов должностей, <br/>
    - идентификатор сотрудника<br/>

3. Возможность создать совместительной должности: <br/>
    Параметры:
    - Название должности,<br/>
    - Ставка<br/>

4. Возможность отправить сотрудника в отпуск на определенное время: <br/>
    Параметры:
    - идентификатор сотрудника, <br/>
    - время начала,<br/>
    - время окончания<br/>

5. Возможность отправить сотрудника на больничный:<br/>
    Параметры:
    - идентификатор сотрудника<br/>
    - время окончания<br/>

6. Возможность продлить больничный сотруднику: <br/>
    Параметры:
    - идентификатор сотрудника<br/>
    - время окончания<br/>

7. Возможность вернуть сотрудника с больничного досрочно:<br/>
    Параметры:
    - идентификатор сотрудника<br/>


## Запросы

1. ### Получение профиля сотрудника:<br/> 
    #### Параметры:<br/>
    - идентификатор сотрудника<br/>
    #### Данные:<br/>
    - Список должностей сотрудника,<br/>
    - В отпуске ли сотрудник,<br/>
    - На больничном ли сотрудник,<br/>
    - Является сотрудник совместителем<br/>

2. ### Получение истории больничных сотрудника:<br/>
    #### Параметры:<br/>
    - идентификатор сотрудника<br/>
    #### Данные:<br/>
    - Список больничных сотрудника<br/>

3. ### Получение истории отпусков:<br/>
    #### Параметры:<br/>
    - идентификатор сотрудника<br/>
    #### Данные:<br/>
    - Список отпусков сотрудника<br/>

4. ### Получение списка должностей:<br/>
    #### Параметры:<br/>
    - идентификатор сотрудника<br/>
    #### Данные:<br/>
    - Список должностей которые можно добавить сотруднику<br/>
