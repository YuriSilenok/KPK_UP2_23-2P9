**Вариант №5. Сервис факультетов/отделений**

**Добавить отделение**  
Информация, требуемая для создания отделения

| Параметр | Обязательность | Тип | Ограничение | Значение по умолчанию |
| :---- | :---- | :---- | :---- | :---- |
| name | Обязательно | Строка | Макс. 150 символов | |
| abbreviation | Обязательно | Строка | Макс. 20 символов | |
| room_number | Обязательно | Целое число | Больше 0 | |
| head_id | Обязательно | Целое число | | |

Уникальные комбинации параметров:

* name должно быть полностью уникальным.  
* abbreviation должно быть полностью уникальным.

Информация, возвращаемая в случае удачного создания отделения:

| Параметр | Тип |
| :---- | :---- |
| id | Целое число |
| name | Строка |
| abbreviation | Строка |
| room_number | Целое число |
| head_id | Целое число |
| is_active | Логический |

**Изменить отделение по ID**  
Входные параметры

| Параметр | Обязательность | Тип | Ограничение | Значение по умолчанию |
| :---- | :---- | :---- | :---- | :---- |
| head_id | Обязательно | Целое число | | |
| id | Обязательно | Целое число | | |
| name | Опционально | Строка | Макс. 150 символов | |
| abbreviation | Опционально | Строка | Макс. 20 символов | |
| room_number | Опционально | Целое число | Больше 0 | |

Выходные параметры

| Параметр | Тип |
| :---- | :---- |
| id | Целое число |
| name | Строка |
| abbreviation | Строка |
| room_number | Целое число |
| head_id | Целое число |
| is_active | Логический |

**Удаление отделения по ID**  
Информация, возвращаемая при удалении отделения:

| Возвращаемое значение | Тип | Сообщение |
| :---- | :---- | :---- |
| True | Логический | Отделение успешно удалено |
| False | Логический | Отделение не удалено или не найдено |

**Получить отделение по ID**  
Информация, возвращаемая в случае удачного поиска отделения по ID:

| Параметр | Тип |
| :---- | :---- |
| id | Целое число |
| name | Строка |
| abbreviation | Строка |
| room_number | Целое число |
| head_id | Целое число |
| is_active | Логический |

Получить список отделений по заданным параметрам:

| Параметр | Тип | Описание |
| :---- | :---- | :---- |
| name | Строка | Поиск по точному совпадению или подстроке (опционально) |
| abbreviation | Строка | Поиск по точному совпадению (опционально) |
| head_id | Целое число | Фильтрация отделений по конкретному заведующему (опционально) |

Информация, возвращаемая в виде списка отделений:

| Параметр | Тип |
| :---- | :---- |
| id | Целое число |
| name | Строка |
| abbreviation | Строка |
| room_number | Целое число |
| head_id | Целое число |
| is_active | Логический |
