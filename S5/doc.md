**Вариант №5. Сервис факультетов/отделений**

**Добавить отделение**  
Информация, требуемая для создания отделения

| Параметр | Обязательность | Тип | Ограничение | Значение по умолчанию |
| :---- | :---- | :---- | :---- | :---- |
| name | Обязательно | Строка | Уникальное значение |  |
| abbreviation | Обязательно | Строка | Уникальное, только заглавные буквы |  |
| room_number | Обязательно | Целое число | Больше 0 |  |
| head_id | Обязательно | Целое число | Больше 0,  |  |

Уникальные комбинации параметров:

* name должно быть полностью уникальным.  
* abbreviation должно быть полностью уникальным.

Информация, возвращаемая в случае удачного создания отделения:

| Параметр | Тип |
| :---- | :---- |
| id | Целое число |
| name | Строка |
| abbreviation | Строка |
| room_number | Целое число |
| head_id | Целое число |
| is_active | Логический |

**Изменить отделение по ID**  
Входные параметры

| Параметр | Обязательность | Тип | Ограничение | Значение по умолчанию |
| :---- | :---- | :---- | :---- | :---- |
| head_id | Обязательно | Целое число | Больше 0 | NULL |
| id | Целое число |
| name | Строка |
| abbreviation | Строка |
| room_number | Целое число |
| head_first_name | Строка |
| head_last_name | Строка |
| specialties_count | Целое число |
| specialty_ids | Список целых чисел |

**Удаление отделения по ID**  
Вернет, если отделение удалено:
| Возвращаемое значение | Тип |
| :---- | :---- |
| True | Логический |

Вернет, если отделение не удалено:
| Возвращаемое значение | Тип |
| :---- | :---- |
| False | Логический |
