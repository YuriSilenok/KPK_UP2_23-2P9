**Вариант №5. Сервис факультетов/отделений**

**Добавить отделение**  
Информация, требуемая для создания отделения

| Параметр | Обязательность | Тип | Ограничение | Значение по умолчанию |
| :---- | :---- | :---- | :---- | :---- |
| name | Обязательно | Строка | Макс. 150 символов | |
| abbreviation | Обязательно | Строка | Макс. 20 символов | |
| room_number | Обязательно | Целое число | Больше 0 | |
| head_id | Обязательно | Целое число | | |

Уникальные комбинации параметров:

* name должно быть полностью уникальным.  
* abbreviation должно быть полностью уникальным.

Информация, возвращаемая в случае удачного создания отделения:

| Параметр | Тип |
| :---- | :---- |
| id | Целое число |
| name | Строка |
| abbreviation | Строка |
| room_number | Целое число |
| head_id | Целое число |
| is_active | Логический |

**Изменить отделение по ID**  
Входные параметры

| Параметр | Обязательность | Тип | Ограничение | Значение по умолчанию |
| :---- | :---- | :---- | :---- | :---- |
| head_id | Обязательно | Целое число | | NULL |
| id | Обязательно | Целое число | | |
| name | Опционально | Строка | Макс. 150 символов | |
| abbreviation | Опционально | Строка | Макс. 20 символов | |
| room_number | Опционально | Целое число | Больше 0 | |
| first_name | Опционально | Строка | Макс. 50 символов | |
| last_name | Опционально | Строка | Макс. 50 символов | |
| specialties_count | Опционально | Целое число | Больше или равно 0 | |
| specialty_ids | Опционально | Список | | Пустой список |

Выходные параметры

| Параметр | Тип |
| :---- | :---- |
| id | Целое число |
| name | Строка |
| abbreviation | Строка |
| room_number | Целое число |
| head_id | Целое число |
| first_name | Строка |
| last_name | Строка |
| specialties_count | Целое число |
| specialty_ids | Список целых чисел |
| is_active | Логический |

**Удаление отделения по ID**  
Вернет, если отделение удалено:
| Возвращаемое значение | Тип |
| :---- | :---- |
| True | Логический |

Вернет, если отделение не удалено:
| Возвращаемое значение | Тип |
| :---- | :---- |
| False | Логический |
