### Room Equipment Service (Сервис оборудования)
#### Вариант 18

#### Создание оборудования в кабинете
| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
|---|---|---|---|---|---|
| equipment_names | Названия единиц оборудования | обязательно | Список строк | | |
| room_name | номер кабинета | обязательно | строка | Больше 0 | |

`equipment_id` и `room_id` создаются в БД автоматически

В случае удачного создания оборудования в кабинете возвращается:
| Параметр | Тип |
|---|---|
| equipment_ids | Список целых чисел |
| equipment_names | список строк |
| room_id | целое число |
| room_name | строка |
| is_active | булевое значение |
`is_active` выставляется автоматически при создании оборудования в состояние True.


#### Изменить список оборудования в кабинете
| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
|---|---|---|---|---|---|
| equipment_names | Названия единиц оборудования | обязательно | Список строк | | |
| room_id | id кабинета | обязательно | целое число | Больше 0 | |

Список оборудования полностью перезаписывается. Старое оборудование меняет статус `is_active` на False

В случае удачного изменения списка оборудования в кабинете возвращается:
| Параметр | Тип |
|---|---|
| equipment_ids | Список целых чисел |
| equipment_names | Список строк |
| room_id | целое число |
| room_name | строка |
| is_active | булевое значение |


#### Изменить статус оборудования кабинета
| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
|---|---|---|---|---|---|
| equipment_id | id оборудования | обязательно | целое число | Больше 0 | |
| is_active | статус оборудования | необязательно | булевое значение | | True |

В случае удачного изменения статуса оборудования возвращается:
| Параметр | Тип |
|---|---|
| is_active | булевое значение |
| equipment_id | целое число |

В случае неудачного изменения статуса оборудования возвращается:
| Параметр | Тип | Сообщение |
|---|---|---|
| message | Строка | Оборудование не найдено |


#### Удалить оборудование в кабинете по id оборудования
Данные из БД не удаляются, удалённым (неактивным) данным присваивается статус `is_active` в значение False

Вернёт, если кабинет был успешно удалён
| Параметр | Тип | Сообщение |
|---|---|---|
| message | Строка | Оборудование удалено |

Вернет ошибку, если оборудование не найдено или уже удалено
| Параметр | Тип | Сообщение |
|---|---|---|
| message | Строка | Оборудование не найдено или не удалось удалить |


#### Получить оборудование кабинета по номеру кабинета
Информация возвращаемая в случае удачного получения в виде списка всего оборудования кабинета:
| Параметр | Тип |
|---|---|
| equipment_id | целое число |
| equipment_name | строка |
| room_id | целое число |
| is_active | булевое значение |


#### Получить список оборудования в кабинетах по параметрам
| Параметр | Тип | Описание |
|---|---|---|
| room_name | строка | Частичный поиск без учёта регистра |
| equipment_ids | список целых чисел | Поиск по одному или нескольким id оборудования |
| is_active | булевое значение | Поиск по статусу доступности оборудования |

Информация возвращаемая в случае удачного получения в виде списка оборудования
| Параметр | Тип |
|---|---|
| equipment_ids | Список целых чисел |
| room_name | строка |
| room_id | целое число |
| is_active | булевое значение |
